# Eira HDPE Panel Armchair Design Spec

## 1. 设计目标

Eira 是一款单人户外休闲扶手椅，面向发泡 PE / HDPE 板材 CNC 切割、螺丝组装、拆装运输和平板包装。它吸收了直板条花园椅、厚板塑木椅和平板化 HDPE 家具的结构思路，但不复制任何现有产品。

明确排除：

- 一体注塑椅、廉价白色 monobloc 塑料椅
- 藤编、仿藤编、rattan、wicker 结构或表面语言
- 美式 Adirondack 的大三角侧面、超宽扶手、深斜躺座面
- 金属折叠椅、布艺露营椅、太阳躺椅和 chaise lounge

## 2. 第一版尺寸

| 项目 | 建议值 |
| --- | ---: |
| 整体宽度 | 660 mm |
| 整体深度 | 650 mm |
| 整体高度 | 820 mm |
| 侧板内净宽 | 610 mm |
| 座面深度 | 500 mm |
| 座面前缘高度 | 440 mm |
| 座面后缘高度 | 420 mm |
| 靠背后仰角 | 10 deg |
| 扶手前端高度 | 640 mm |
| 扶手后端高度 | 625 mm |
| 扶手宽度 | 82 mm |

坐姿是“户外休闲餐椅和 lounge chair 的中间值”：比餐椅放松，但不做深躺。座面只有轻微后低，方便起身，也避免 Adirondack 感。

## 3. 结构组成

主结构由平板件组成：

- 左右侧框：25 mm 板，镜像 CNC 切割，形成前腿、后腿、扶手支撑、座面支撑和下部开窗。
- 扶手面板：25 mm 板，单独覆盖在侧框顶部，圆角处理，便于更换颜色或材质。
- 前 / 后横梁：25 mm 板，连接左右侧框，承担座面板条支撑和横向抗扭。
- 座面板条：20 mm 板，6 根横向板条，保留排水缝。
- 靠背组件：20 mm 竖向板条 + 25 mm 上下背横梁，整体后仰约 10 deg。
- 内侧角撑：25 mm 三角板，安装在前后横梁与侧框交接处，提高侧向稳定性。
- 底部横撑：25 mm 板，安装在前腿和后腿下部之间，减少左右晃动。

## 4. 材料与边缘

建议材料：

- 侧框、扶手、横梁、角撑：25 mm 发泡 PE / HDPE 板
- 座面 / 靠背板条：20 mm 发泡 PE / HDPE 板
- 五金：A2 或 A4 不锈钢，优先 M6 螺栓 + 桶形螺母 / 嵌入螺母

边缘建议：

- 手接触边：R6-R10 圆角
- 普通外轮廓：R4-R6 圆角
- 板条端头：R8-R12 圆角
- 所有沉头孔边缘倒角，避免应力集中

## 5. 连接原则

- 主结构不依赖胶水。
- 横梁与侧框使用 M6 贯穿连接或桶形螺母连接。
- 座面板条用沉头螺丝固定到前后横梁，板条孔做长圆孔以吸收热胀冷缩。
- 靠背板条固定到上 / 下背横梁，再把靠背组件整体连接到左右侧框后立柱。
- 外侧允许保留少量圆形螺丝点，作为“可拆装板件家具”的结构语言。

## 6. 承重路径

人体重量从座面板条传到前后横梁，再传到左右侧框的前后腿。靠背受力传到后立柱和后横梁。角撑负责限制前后横梁与侧框之间的转动，底部横撑负责减少侧向晃动。

不要让座面板条只靠螺丝悬挂在薄边上；板条下方必须有连续支撑面或足够宽的横梁接触面。

## 7. 打样默认

第一版以结构可行和视觉方向为主。建议先做 1:1 白模或低成本板材样，再根据坐感调整：

- 如果坐姿太直：靠背角度从 10 deg 调到 12 deg
- 如果起身困难：座面后缘提高 10-15 mm
- 如果左右晃动：加大角撑或增加底部斜撑
- 如果扶手显厚重：扶手宽度从 82 mm 调到 70-75 mm
